# Koridor Lambası Gecikme Sendikası

Bu depo, apartman koridorundaki lambanın seni gördüğü halde “birazdan yanarım, toplu sözleşme maddesi 7” demesini bilimsel ciddiyetle modeller. Bilim burada çok yorulmuştur. Lamba dinlenmektedir.

## Misyon

İnsan koridorun yüzde seksenini karanlıkta geçirir. Lamba, tam ayakkabılığa ulaşıldığı anda kahramanca yanar. Sendika bunu “zamanında hizmet” sayar. Biz tutanak tutarız.

## Kurulum

Python 3 yeter. Bağımlılık yoktur, çünkü lamba da bağımlılık kabul etmez.

```bash
python3 lamba_sendikasi.py
python3 lamba_sendikasi.py --koridor 18 --hiz 1.3 --el-cirpmasi 2 --protokol
```

## Ne çıkar

- Karanlıkta geçen metre ve saniye
- Lambanın resmi mazereti
- Alkışın sendikal ihlal sayılıp sayılmadığı
- Ödenecek hayali gecikme aidatı
- Kapıya yapıştırılacak tek sayfalık tutanak

`--protokol` bayrağı, lambanın neden bazı geçişlerde daha erken uyandığını açıklamaz. Açıklamaması da bir açıklamadır. Ayrıntı bakım dolabındadır: `bakim/not.b64`.

## Hukuki dayanak

Dayanak yoktur. Yine de şu maddeler yürürlüktedir:

1. Lamba, sensör değil sendika üyesidir.
2. El çırpma, toplu iş sözleşmesine aykırı alkıştır.
3. “Az önce yandı” cümlesi geçerli savunma değildir, geçerli mizahtır.
4. Bu yazılım bir ampul değiştirmez. Ampul zaten değişmiyordu.
